# Tnvios AI Build Documentation Pack

This folder contains implementation-contract documents for building Tnvios with AI coding agents.

## How to Use

Before asking AI to generate code, feed it these core documents:

1. `docs/00-master-context.md`
2. `docs/01-tech-stack.md`
3. `docs/02-monorepo-structure.md`
4. `docs/03-ai-coding-rules.md`

Then add the specific documents relevant to the task.
