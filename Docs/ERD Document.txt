# Tnvios Entity Relationship Document (ERD)

Version: 1.0

Status: Core Platform Data Model

Classification: Master Data Architecture

Priority: Critical

---

# Purpose

This document defines the core entities, relationships, ownership rules, and inheritance structure of Tnvios.

The ERD acts as the foundation for:

* Core Platform
* Core Engines
* Modules
* AI Layer
* Workflows
* Security
* Analytics

---

# Core Entity Hierarchy

```text
Tenant
 │
 └── Organization
      │
      ├── Business Unit
      │     │
      │     └── Department
      │            │
      │            └── Team
      │                   │
      │                   └── Membership
      │                          │
      │                          └── User
      │
      ├── Customer
      ├── Vendor
      ├── Partner
      ├── Module
      ├── Workflow
      └── AI Agent
```

---

# Global Base Entity

Every business entity inherits:

```sql
id UUIDV7 PK

tenant_id UUID FK

organization_id UUID FK

created_at TIMESTAMPTZ

updated_at TIMESTAMPTZ

deleted_at TIMESTAMPTZ

created_by UUID FK

updated_by UUID FK
```

# Future Module Extension Strategy

Core Platform Owns:

* Organization
* Identity
* Permissions
* Workflows
* Events
* Audit
* Files
* AI

Modules Extend Core:

CRM
└── crm_customers
└── crm_leads

Finance
└── finance_invoices
└── finance_payments

HR
└── hr_leave_requests
└── hr_payroll

Manufacturing
└── manufacturing_orders
└── manufacturing_assets

Every module inherits:

tenant_id

organization_id

created_by

updated_by

and integrates with:

Permission Engine

Workflow Engine

Event Engine

Audit Engine

AI Engine
