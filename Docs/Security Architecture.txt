# Enterprise Collaboration and Data Movement Security

Onboarding, contextual help, activity feeds, comments, mentions, inbound email, imports, and exports are security-sensitive platform capabilities.

Rules:

* Activity feeds must filter entries by tenant, organization, permission, record access, and field-level security.
* Comments must inherit the target entity security model.
* Mentions must only notify users who can access the target entity.
* Inbound email actions require sender verification, signed reply tokens, permission checks, workflow policy validation, attachment scanning, and audit logging.
* Imports must validate every row and must never bypass normal API validation, permission checks, audit logging, or event publishing.
* Exports must enforce field-level security before file generation and must create export audit logs.
* Generated export files must use private storage and signed URLs with expiration.
