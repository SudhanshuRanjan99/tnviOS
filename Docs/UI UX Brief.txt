# Tnvios UI/UX Brief

Version: 1.0

Status: Product Design Foundation

---

# Vision

Design the world's most intuitive business operating system.

Tnvios should feel:

* Simpler than SAP
* More powerful than Odoo
* More connected than Salesforce
* More modern than traditional ERP software
* AI-first without being AI-dependent

The platform should serve organizations ranging from startups to global enterprises.

---

# Design Principles

## 1. Context First

Users should only see what matters to them.

A CEO should not see payroll forms.

An employee should not see treasury dashboards.

A vendor should not see CRM pipelines.

The interface adapts based on role and context.

---

## 2. One Platform, Many Experiences

Tnvios is one application.

However each user experiences a different product.

Examples:

Chairman → Executive Workspace

HR Manager → HR Workspace

Employee → Employee Workspace

Customer → Customer Portal

Vendor → Vendor Portal

Partner → Partner Portal

---

## 3. AI Everywhere

AI is not a separate screen.

AI exists throughout the platform.

Examples:

Generate reports

Explain metrics

Find documents

Create workflows

Answer questions

Users should interact with AI naturally.

---

## 4. Dashboard Driven

Every role starts from a dashboard.

The dashboard becomes the operating center.

No user should need to navigate deeply for common actions.

---

## 5. Enterprise Simplicity

Avoid:

Complex ERP interfaces

Huge menu trees

Dense tables everywhere

Too many clicks

Prioritize:

Clear navigation

Progressive disclosure

Smart defaults

Modern layouts

# Enterprise UI Platform Addendum

Tnvios UI is a governed enterprise design system, not raw Tailwind usage.

Frontend UI standard:

* Tailwind CSS as utility styling layer
* shadcn/ui as base component source
* Radix UI primitives where applicable
* Tnvios UI Kit exported from @tnvios/ui
* Tnvios Platform Form Engine using controlled components
* Zod validation
* Tiptap rich text editor

Modules must import UI components only from @tnvios/ui.

Raw Tailwind is allowed inside the UI Kit. Raw Tailwind in business modules is restricted and reviewed.

Required enterprise UX capabilities:

* Organization onboarding flow
* Role-based onboarding checklists
* Module setup flows
* In-app help and contextual guidance
* Guided tours
* Empty-state guidance
* Activity feed and entity timelines
* Comments and @mentions
* Rich text editing
* Email-to-action flows
* Import/export flows for every module

These capabilities must be shared platform services. Modules may not implement separate onboarding, comments, activity feed, import/export, or contextual help systems.
