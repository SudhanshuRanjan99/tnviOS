# Tnvios Backend Schema Specification

Version: 1.0

Status: Core Platform Database Architecture

Database: PostgreSQL

Architecture: Multi-Tenant Modular Platform

---

# Core Design Principles

Every record must belong to:

Tenant

Organization

Business Unit

Department

User

All modules inherit these relationships.

---

# Global Base Model

Every table inherits:

```sql
id UUID PRIMARY KEY

tenant_id UUID NOT NULL

organization_id UUID

created_at TIMESTAMPTZ

updated_at TIMESTAMPTZ

deleted_at TIMESTAMPTZ

created_by UUID

updated_by UUID
```

# Hierarchy Model

```text
Tenant
│
└── Organization
     │
     └── Business Unit
           │
           └── Department
                 │
                 └── Team
                       │
                       └── User
                              │
                              ├── Employee
                              ├── Customer
                              ├── Vendor
                              └── Partner
```

All modules inherit this hierarchy.

This becomes the single source of truth across the entire platform.
