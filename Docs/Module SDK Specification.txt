# Tnvios Module SDK Specification

Version: 1.0

Status: Platform Architecture

Classification: Core Framework

---

# Purpose

The Module SDK defines how modules are built, installed, managed, secured, and integrated within Tnvios.

All modules must use the SDK.

No module may bypass SDK standards.

Examples:

CRM

HR

Finance

Payroll

Projects

Travel

Healthcare

Manufacturing

Marketplace

AI Agents

Third-Party Extensions

---

# Core Philosophy

Tnvios Core owns:

Identity

Organizations

Workflows

Notifications

Files

AI

Modules consume platform services.

Modules never reimplement platform services.

# Enterprise Shared Service Integration Rules

Every module must integrate with Tnvios shared platform services.

Modules may register:

* onboarding steps
* help contexts
* activity event mappings
* commentable entities
* mentionable entity rules
* import templates
* export templates
* inbound email action handlers

Modules may not implement independent systems for onboarding, contextual help, activity timelines, comments, mentions, inbound email actions, imports, or exports.

All module integrations must enforce tenant isolation, organization isolation, permissions, policies, audit logging, and event publishing.
