# Tnvios Application Flow Document (AFD)

Version: 1.0

Status: System Flow Specification

# 1. Purpose

This document defines the application flow of Tnvios.

It describes:

* User journeys
* Organization setup
* Module installation
* Permission assignment
* Workflow execution
* AI interactions
* Customer interactions
* Vendor interactions
* Partner interactions

The objective is to ensure a consistent experience across the entire platform.

# Enterprise Platform Experience Flows

Tnvios includes enterprise-grade experience flows in addition to module-specific flows.

## Onboarding Flow

Organization registration
↓
Email verification
↓
MFA setup
↓
Company profile
↓
Business units
↓
Departments
↓
Teams
↓
Users
↓
Roles and permissions
↓
Module setup
↓
Workspace activation

## Contextual Guidance Flow

User opens page
↓
System resolves role, module, permission, and page context
↓
Relevant help content, tours, empty states, and AI guidance are displayed
↓
Progress is saved per user

## Activity Timeline Flow

Business action occurs
↓
Audit log and domain event are created
↓
Activity Feed Engine creates timeline entry
↓
Entry becomes visible based on permission and record access

## Comments and Mentions Flow

User comments on entity
↓
System validates entity access
↓
System validates mentioned users can access the entity
↓
Notifications are created
↓
Activity timeline is updated

## Email-to-Action Flow

Inbound email received
↓
Sender and signed reply token validated
↓
Tenant, organization, user, entity, and action resolved
↓
Permission and workflow policy checked
↓
Action executed or routed for review
↓
Audit log and event created

## Import / Export Flow

User uploads or requests data
↓
Permission and field-level security checked
↓
Background job created
↓
Validation, mapping, import/export, file generation, and audit are processed
↓
Result file and activity entry are created
